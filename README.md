Project Exhibition (anishidra-portfolio)

  A modern and responsive project exhibition website designed to showcase a project, its owners, development team, screenshots, social profiles, and live project link.



=> Features:

    -->  Responsive navigation
    -->  Large project presentation
    -->  Project description and information
    -->  Project owners section
    -->  Developer profiles and roles
    -->  Portfolio, GitHub, and LinkedIn links
    -->  Project screenshot gallery
    -->  Image lightbox
    -->  Project social links
    -->  Live project CTA
    -->  Two-column portfolio footer
    -->  Mobile-friendly design



=> Technologies:

    -->  HTML5
    -->  CSS3
    -->  JavaScript



=> Structure:

    project/
    ├── images/
        ├── desktop/
        ├── logo/
        └── mobile
    ├── index.html
    ├── README.md
    ├── script.js
    └── style.css



=> Usage:

    -->  Replace the placeholder content in index.html.
    -->  Add your images inside the assets folder.
    -->  Update the project and social links.
    -->  Open index.html in your browser.
